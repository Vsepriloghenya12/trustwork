# TrustWork — дизайн-бриф для проработки визуала

Этот документ самодостаточен: в нем есть все, чтобы спроектировать экраны, не видя кодовую базу. Результат вернется разработчику и будет перенесен в приложение один в один.

## Что нужно на выходе

**Один самодостаточный HTML-файл** с мокапами экранов:

- Все экраны шириной **375px** (iPhone), расположены рядом — сеткой или в горизонтальный ряд, у каждого подпись с названием.
- Весь CSS — инлайном в `<style>` внутри файла. Без внешних библиотек и фреймворков (никаких Tailwind/Bootstrap по CDN).
- Шрифты подключить с Google Fonts: `Unbounded` (500, 600) и `Manrope` (400–800) — у обоих есть кириллица.
- Иконки — инлайн-SVG (обводка ~1.9px, скругленные концы), без иконочных шрифтов.
- JavaScript не нужен: это статические мокапы состояний.

Совет по процессу: прорабатывать по 1–2 экрана за итерацию, начиная с самых важных — Лента и Карточка проекта. Они задают язык всему приложению.

## 1. Продукт в двух абзацах

**TrustWork** — мобильная фриланс-платформа «нового поколения»: отклики бесплатны, а бюджет проекта заказчик замораживает в эскроу **до** начала работы. Фрилансер видит в ленте только проекты с уже защищенной оплатой. Заказчик выбирает исполнителя по коротким питчам, вся переписка — во внутреннем чате, контакты автоматически скрываются, спор решает арбитраж.

Аудитория: фрилансеры (дизайн, разработка, тексты, маркетинг, видео), уставшие от платных откликов и кидалова, и заказчики — малый бизнес и частные лица. Язык интерфейса — русский. Тон — спокойный, уверенный, без канцелярита и без агрессивного маркетинга. Ключевая эмоция: **«деньги уже под замком — работай спокойно»**.

## 2. Действующая дизайн-система (отправная точка)

Стиль: **финтех-минимализм** — светлый фон, белые карточки с мягкими тенями, крупные кнопки, много воздуха. Можно развивать и улучшать, но основа ниже утверждена владельцем продукта.

### Цвета

| Токен | HEX | Использование |
|---|---|---|
| Индиго темный | `#3B3486` | Логотип, заголовки-акценты, суммы |
| Индиго яркий (primary) | `#5B4FE9` | Главные кнопки, активные состояния, ссылки |
| Индиго-подложка | `#EEECFD` | Фон вторичных кнопок, активный пункт навигации |
| Фон экрана | `#F5F6FB` | Общий фон |
| Поверхность | `#FFFFFF` | Карточки, панели |
| Текст основной | `#1C1B33` | |
| Текст вторичный | `#626389` | Подписи, метаданные |
| Линии | `#E7E8F2` | Разделители, рамки полей |
| **Зеленый доверия** | `#0E9F6E` | ВСЁ про эскроу и верификацию: бейджи, панель «Безопасная сделка», кнопка заморозки |
| Зеленая подложка | `#E6F7F0` (рамка `#BFEBD9`) | Фон эскроу-элементов |
| Ошибка | `#D92D20` | |

Правило: зеленый зарезервирован за темой «деньги защищены». Не использовать его для декора.

### Типографика

- **Unbounded** (500/600) — витринный шрифт: логотип, заголовки экранов, суммы бюджетов. Он широкий и характерный, применять дозированно, кегль 18–26.
- **Manrope** (400–800) — весь остальной текст. Жирность 700–800 для имен и заголовков карточек, 400–500 для описаний.

### Форма

- Радиусы: карточки 20px, кнопки и поля 14px, чипы/бейджи — полное скругление (pill).
- Тень карточек: `0 6px 24px rgba(59,52,134,0.09)`; тень главной кнопки: `0 8px 20px rgba(91,79,233,0.28)`.
- Кнопки: высота 52px, ширина 100%, текст 15–16px жирный.
- Минимальная зона касания — 44px.
- Контраст текста — не ниже WCAG AA (вторичный текст `#626389` на белом — проходит).

### Фирменный элемент — эскроу-шкала

Три этапа сделки: **Заморожено → В работе → Выплачено** (точки, соединенные линией; пройденные — зеленые). Появляется в зеленой панели «Безопасная сделка» на карточке проекта и в шапке чата. Это главный узнаваемый элемент платформы — его можно сделать выразительнее (анимация, замочек на активной точке, пломба), но нельзя убирать и менять смысл этапов.

## 3. Экраны

Нижняя навигация (на экранах 1–4, 6): **Лента · Поиск · Чаты · Профиль** — 4 иконки с подписями, активный пункт — индиго на светло-индиго подложке.

### 3.1. Лента проектов (главный экран)

- Шапка: приветствие «Здравствуйте, Анна!» (мелко, серым) + логотип TrustWork; справа кнопка-иконка уведомлений; у заказчика — еще кнопка «+» (создать проект).
- Подзаголовок-ярлык: «ПРОЕКТЫ С ЗАЩИЩЕННОЙ ОПЛАТОЙ».
- Карточки проектов, у каждой:
  - зеленый pill-бейдж с замком «Оплата в эскроу» + дата справа;
  - заголовок (700), описание в 2 строки;
  - бюджет крупно шрифтом Unbounded («35 000 ₽») + до 3 тегов-чипов;
  - низ: аватар-инициалы, имя заказчика, галочка верификации, рейтинг со звездой.
- Пустое состояние: «Пока пусто. Здесь появятся проекты, у которых бюджет уже заморожен в эскроу».

Демо-контент для мокапа: «Лендинг для студии йоги» 35 000 ₽ (разработка, лендинг); «Монтаж видео для YouTube-канала» 20 000 ₽ (видео, монтаж); «Тексты для Telegram-канала о финансах» 15 000 ₽ (тексты, маркетинг).

### 3.2. Карточка проекта

- Кнопка «назад» + pill статуса («Открыт набор» / «В работе» / «Завершен»).
- Заголовок проекта (21px).
- Карточка заказчика: аватар, имя, галочка верификации, «★ 4.8 · 12 отзывов» или «Новый заказчик».
- **Зеленая панель «Безопасная сделка: 35 000 ₽ заморожено в эскроу»** с эскроу-шкалой. Это смысловой центр экрана.
- Чипы: бюджет, срок («до 25 авг.»), теги.
- Блок «Описание задачи».
- Действия по ролям (в мокапе показать вариант фрилансера + можно второй кадр для заказчика):
  - гость: «Войти, чтобы предложить себя»;
  - фрилансер: крупная кнопка «Предложить себя» → шторка снизу с textarea питча («Короткий питч работает лучше шаблона») и кнопкой «Отправить питч»;
  - после отклика: pill «Питч отправлен — заказчик видит ваш отклик»;
  - заказчик до заморозки: зеленая кнопка «Заморозить 35 000 ₽ в эскроу» + подпись «После заморозки проект попадет в ленту с бейджем “Оплата гарантирована”»;
  - заказчик при наборе: список питчей (аватар, имя, «3 сделок · Проверенный», текст питча, кнопки «Выбрать исполнителем» и «Написать») + внизу тихая красная кнопка «Отменить проект и вернуть деньги»;
  - заказчик в работе: «Чат с исполнителем» + зеленая «Принять работу и оплатить».

### 3.3. Вход и онбординг (3 шага)

1. **Телефон**: логотип по центру, слоган «Отклики бесплатны. Оплата — под защитой эскроу», поле «+79001234567», кнопка «Получить код из SMS». Ниже — информативный блок «как это работает» (сейчас это список из 3 пунктов, его хочется сделать заметно красивее — можно иллюстративнее, карточками/схемой):
   - «Оплата гарантирована. Заказчик замораживает бюджет в эскроу до начала работы — деньги уже ждут исполнителя»;
   - «Отклики бесплатны. Платформа берет комиссию только с успешной сделки»;
   - «Сделка под защитой. Переписка и файлы хранятся на платформе, спор решает арбитраж».
2. **Код**: 6 ячеек кода, «Отправили код на +7…», кнопки «Войти» и «Изменить номер».
3. **Профиль**: заголовок «Расскажите о себе», два selectable-тайла «Я фрилансер / Ищу проекты» и «Я заказчик / Ищу исполнителей», поле «Имя», кнопка «Начать работу».

### 3.4. Профиль

- Карточка: аватар-инициалы 72px, имя, «Фрилансер · +7 999 …», рейтинг.
- Бейджи: зеленые «Телефон подтвержден», «Проверенный фрилансер» (после 3 сделок); серый чип «Новичок · до статуса “Проверенный”: 2 сделки»; чипы Telegram/GitHub, если привязаны.
- Две стат-карточки: «сделок завершено» и «рейтинг» (цифры — Unbounded).
- Блоки «Навыки» (чипы) и «О себе».
- Кнопки «Редактировать профиль» и тихая красная «Выйти».

### 3.5. Чат сделки (без нижней навигации)

- Шапка: назад, название проекта, подпись «Все договоренности — только здесь».
- **Зеленый баннер «Эскроу активен · 35 000 ₽ заморожено»** с эскроу-шкалой (компактной). Для завершенной сделки: «Сделка завершена · 35 000 ₽ выплачено».
- Сообщения: мои — индиго справа, собеседника — белые слева, время мелко. Если контакты скрыты — подпись в пузыре «Контакты скрыты правилами платформы».
- Пустое состояние: «Начните разговор…».
- Поле ввода + круглая кнопка отправки (52px не обязательно, сейчас 46px).

### 3.6. Список чатов

Строки: аватар, имя собеседника, название проекта (серым, в одну строку), справа зеленый бейдж с суммой эскроу. Пустое состояние: «Чат откроется, когда вы откликнетесь на проект или выберете исполнителя».

### 3.7. Поиск

Поле поиска, чипы популярных тегов (дизайн, разработка, тексты, маркетинг, видео; активный — индиго), результаты — те же карточки, что в ленте. Пустое состояние: «Ничего не нашлось».

### 3.8. Создание проекта (заказчик)

Поля: «Название задачи», «Описание» (textarea), «Бюджет, ₽», «Теги (через запятую)», «Срок (необязательно)». Кнопка «Создать проект» + подпись с замком: «Следующий шаг — заморозка бюджета. Без нее проект не публикуется».

## 4. Что можно менять, а что нельзя

**Можно и нужно:** композиция, иллюстрации, градиенты, пустые состояния, иконки, микроанимации (описать словами), выразительность эскроу-элементов, любые улучшения формулировок в том же тоне.

**Нельзя:** менять смысл статусов и этапов сделки; убирать эскроу-шкалу и зеленое кодирование доверия; добавлять несуществующие функции (видеозвонки, сторис, платные поднятия); темная тема — не сейчас; кегль основного текста меньше 13px.
